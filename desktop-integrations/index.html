🔗Desktop Integrations & Companion API

Boxxy Terminal exposes a reactive, zero-polling IPC interface over your user's Session D-Bus. Whether you are building a top-bar panel extension, a status bar module, or a quick-launcher plugin for =GNOME Shell=, =KDE Plasma=, =COSMIC=, =Waybar=, =Hyprland=, =Rofi=, or =Walker=, you can monitor boxxy-agent, restore detached background shells, inspect pending AI reminders, and focus or spawn characters in real time.

For a complete production reference implementation, check out the official GNOME Shell Boxxy Companion Extension.

🔗Bus & Service Details

All companion methods and push signals live on a single D-Bus object in boxxy-agent:

  • Bus: Session Bus (DBUS_SESSION_BUS_ADDRESS)
  • Service Name (Stable): dev.boxxy.BoxxyAgent
  • Service Name (--dev Mode): dev.boxxy.BoxxyAgent.Devel (or dev.boxxy.BoxxyAgent.Devel.i_<slug> for named --instance <slug> runs)
  • Object Path: /dev/boxxy/Agent
  • Interface: dev.boxxy.BoxxyTerminal.Agent

Note: Boxxy is written in Rust with zbus, which maps Rust snake_case method names to PascalCase on the D-Bus wire. Complex payloads use UTF-8 JSON strings (s) so status bar scripts (jq, Python, GJS, QML, Rust) can consume them without custom struct marshalling.

🔗Best Practice: Watch Without Auto-Starting

Companion applets should observe dev.boxxy.BoxxyAgent name ownership (NameOwnerChanged / Gio.bus_watch_name) and pass NO_AUTO_START when calling methods so an idle status bar never spawns boxxy-agent on its own.

🔗1. Daemon Status & Lifecycle API

MethodSignatureTypeDescription
GetDaemonStatus() -> (s)MethodReturns a JSON snapshot (DaemonStatusSnapshot) summarizing daemon version, power state, Dream Cycle status, and active session counts in a single call.
GetVersion() -> (s)MethodReturns the running daemon version string (appends -stale if the on-disk binary was upgraded since launch).
GetConfigDir() -> (s)MethodReturns the active configuration directory path (e.g. ~/.config/boxxy-terminal).
RequestReload() -> ()MethodFlushes telemetry and reloads boxxy-agent in-place via execvp(), preserving PID and background shells.
RequestStop() -> ()MethodGracefully terminates active sessions, flushes telemetry, and stops the daemon.

🔗2. Character Roster, Focus & Spawning API

Method / SignalSignatureTypeDescription
GetRegistrySnapshot() -> (s)MethodReturns a JSON RegistrySnapshot containing the full character catalog, active claims, and monotonic revision.
RequestFocusPane(s) -> ()MethodAccepts pane_id. Raises the Boxxy window and focuses that pane (or queues restoration if the pane is detached in the background).
RequestSpawnCharacter(s, s) -> ()MethodAccepts (character, cwd) where character is a UUID, slug (niko-una), or display name (Niko), and cwd is an optional working directory ("" for default). If the character is already active, focuses its pane; otherwise opens a new Claw tab with that character claimed (queuing for startup if no Boxxy window is open).
ClaimsChanged(s)SignalBroadcast whenever a character is claimed, released, or reloaded. Payload matches GetRegistrySnapshot JSON.
SpawnCharacterRequested(s, s)SignalEmitted to open Boxxy UI windows ((character_id, cwd)) when RequestSpawnCharacter targets an available character while a window is attached.

🔗3. Detached Background Shells API

When a user closes a Boxxy tab or window while a foreground command (cargo build, nvim, top, pacman -Syu, or a background AI session) is running, boxxy-agent keeps the PTY alive in a 4 MB ring buffer so any companion applet can restore or terminate it.

Method / SignalSignatureTypeDescription
GetDetachedSessions() -> (s)MethodReturns a JSON array of DetachedSessionInfo objects for all background shells hosted by boxxy-agent.
RequestRestoreDetached(u) -> ()MethodAccepts pid (u32, or 0 to restore all detached shells preserving split layouts). Restores immediately into an open Boxxy window or queues for boxxy-terminal --present.
TerminateDetachedSession(u) -> ()MethodAccepts pid (u32, or 0 to terminate all detached shells). Disables persistence and sends SIGTERM to the background process group.
DetachedSessionsChanged(s)SignalBroadcast whenever a shell detaches, reattaches, is terminated, or exits. Payload matches GetDetachedSessions.
RestoreDetachedRequested(u, s)SignalInternal UI signal ((pid, cwd)) emitted to attached Boxxy windows when RequestRestoreDetached is called.

🔗4. Pending Reminders & Scheduled Tasks API

Characters in =BoxxyClaw= can schedule timers, interval laps, background commands, and deferred AI queries. Companions can display live countdowns and cancel or jump to any scheduled task.

Method / SignalSignatureTypeDescription
GetPendingTasks() -> (s)MethodReturns a JSON array of PendingTaskInfo sorted by due_at_unix.
CancelPendingTask(s, s) -> ()MethodAccepts (pane_id, task_id) and cancels the scheduled task.
PendingTasksChanged(s)SignalBroadcast whenever a task is scheduled, completed, cancelled, or detached/reattached. Payload matches GetPendingTasks.

    "id": "d290f1ee-6c54-4b01-90e6-d701748f0851",

🔗Quick CLI & Status Bar Examples

🔗busctl (CLI Inspection & Scripting)

# 1. Single-call daemon status summary (pipe to jq!)
busctl --user -j call dev.boxxy.BoxxyAgent /dev/boxxy/Agent \
  dev.boxxy.BoxxyTerminal.Agent GetDaemonStatus | jq -r '.data[0] | fromjson'

# 2. Inspect character catalog and active pane claims
busctl --user -j call dev.boxxy.BoxxyAgent /dev/boxxy/Agent \
  dev.boxxy.BoxxyTerminal.Agent GetRegistrySnapshot | jq -r '.data[0] | fromjson'

# 3. Focus or spawn a character by slug (then raise/launch Boxxy Terminal)
busctl --user call dev.boxxy.BoxxyAgent /dev/boxxy/Agent \
  dev.boxxy.BoxxyTerminal.Agent RequestSpawnCharacter ss "niko-una" ""
boxxy-terminal --present

# 4. Restore all detached background shells
busctl --user call dev.boxxy.BoxxyAgent /dev/boxxy/Agent \
  dev.boxxy.BoxxyTerminal.Agent RequestRestoreDetached u 0
boxxy-terminal --present

# 5. Stop a running `--dev` agent instance cleanly over D-Bus
busctl --user call dev.boxxy.BoxxyAgent.Devel /dev/boxxy/Agent \
  dev.boxxy.BoxxyTerminal.Agent RequestStop

  "return-type": "json",
  "interval": 5,
  "on-click": "boxxy-terminal --present"
}
