🔗Providers

Boxxy connects to LLM providers via rig. Boxxy supports all models from each provider — automatically configuring thinking levels, context windows, and token pricing.

Configure your API keys or custom endpoints in =Preferences= → =APIs=, then assign models to each role (AI Chat, Claw, and Memories & Dreams) in =Preferences= → =Models Selection= or via the quick links in the =Claw Sidebar=.

🔗Web Search Providers

Characters can browse the web in real time to look up documentation, recent releases, or error codes. Enable web search in =Preferences= → =APIs= under Search Engines, and toggle it anytime per pane using the Globe Icon in the message bar (Ctrl + /).

Search ProviderSupported ModelsNotes
Native Provider SearchGemini · OpenAI · AnthropicUses the provider's built-in server-side search — no extra API key required
TavilyAll providersLLM-optimized web search · Automatic fallback for local and custom models

More web search providers are coming soon!

🔗Missing a provider?

New model and search providers are added regularly. If there is a provider you would like to see supported, open an issue on GitHub!
