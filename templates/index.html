Get Boxxy running Native Nightlies · Requires GTK 4.24+
$ 
curl -sSf https://raw.githubusercontent.com/boxxy-dev/boxxy/main/scripts/install.sh | sh
$ 
curl -O https://boxxy-dev.github.io/boxxy-flatpak-remote/boxxy.gpg && \
  flatpak remote-add --user --if-not-exists --gpg-import=boxxy.gpg \
  boxxy https://boxxy-dev.github.io/boxxy-flatpak-remote/repo && \
  flatpak install --user boxxy dev.boxxy.BoxxyTerminal
$ 
nix profile install github:boxxy-dev/boxxy

Try without installing: nix run github:boxxy-dev/boxxy · Flake input: github:boxxy-dev/boxxy

DAILY WORKFLOWS

What you can use Boxxy for every day.

Practical ways Boxxy fits into a real Linux workflow without getting in your way.

Debug Your Linux System

Hit a broken package update, a failing systemd service, or a full disk? Press Ctrl + / and ask “fix this”. Boxxy reads your terminal output, checks logs, and proposes exact commands for your approval.

> "fix this"
Send Tasks to the Background

Running a long build, dev server, or distro upgrade? Close the tab or quit the app with Run in Background. Your shells and characters stay alive in boxxy-agent and restore with their exact split-pane layout.

>_ 2 detached
Set Reminders & Scheduled Tasks

Tell your character “Remind me to check the deploy in 20 minutes”. Even with all Boxxy windows closed, the background daemon keeps counting down and sends a native desktop notification on time.

● 20:00 timer
Chat with Persistent Characters

Pair up with Niko, Levi, or Kuro — or create your own persona. Each character remembers your preferences in human-readable MEMORY.md and consolidates knowledge during idle Dream cycles.
